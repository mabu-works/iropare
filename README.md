## 📖 概要

画像から色を抽出したり、調和のとれたカラーパレットを生成できる静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

## ✨ 機能

- 画像からの色抽出
  - ファイル選択のほか、ドラッグ＆ドロップにも対応
  - Canvasで画像を最大150×150pxに縮小してサンプリングし、RGBを32段階に量子化したバケットの出現頻度（簡易クラスタリング）で代表色を約6色抽出します
  - ほぼ透明な画素は除外し、近すぎる色は間引いてから頻度順に補充します
  - プレビュー表示つき
- 調和パレットの自動生成（5色）
  - HSL色空間で色相の関係を計算するハーモニー方式：おまかせ（ランダム）、アナロジー（類似色）、補色（コンプリメンタリー）、トライアド（三色配色）、スプリット・コンプリメンタリー、モノクローム（同系色）
  - 「新しいパレットを生成」ボタンで再生成できます
- パレット表示とコピー
  - 色見本（スウォッチ）にHEXラベルを表示
  - 色をクリックするとHEXコードをクリップボードにコピーし、フィードバックメッセージを表示します
  - 「HEXをすべてコピー」ボタンで現在のパレットをまとめてコピーできます（半角スペース区切り）
- お気に入り（localStorage保存、最大50件）
  - 現在のパレットを保存し、一覧から読み込み（適用）・個別削除・すべて削除ができます
- テーマ切替（ダーク／ライト、localStorageに保存）
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）

## 📝 使い方

1. 開くと自動でパレットが1つ生成されます。気に入らなければ、調和のタイプを選んで「新しいパレットを生成」を押します。
2. 画像の色を使いたいときは、画像をドラッグ＆ドロップするか、クリックしてファイルを選ぶと、代表色が約6色抽出されてパレットに表示されます。
3. 色をクリックするとHEXコードがコピーされます。
4. 残しておきたいパレットは「お気に入りに保存」を押します。お気に入り一覧の「読み込む」でいつでも再表示できます。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。パレット生成（HSLハーモニー6種）と画像からの色抽出（量子化＋頻度順の代表色）は Web 版と同じ方式で、お気に入りも保存できます（保存先は Web 版の localStorage の代わりに `%APPDATA%\Iropare\favorites.json`）。オフラインで使えます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Iropare.exe` を生成（GitHub Release にはバイナリを添付しない方針のため、exe は各自でビルドします）
- Windows 版ならではの機能として「スポイト」を追加：ボタンを押してから画面上の任意の場所をクリックすると、その画素の色を取得してパレットに追加し、HEXをコピーします（Escで中止。クリック自体は下のウィンドウにも届きます）

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 画像処理はすべてブラウザ内で行われ、サーバーには何も送信されません。お気に入りも localStorage のみに保存されます。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: iropare-v1）。
- 色変換・生成・抽出の純粋ロジックは `js/color-core.js` に分離し、Node の標準テスト（`npm test`、依存なし）で検証しています。
